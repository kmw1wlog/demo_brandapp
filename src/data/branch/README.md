# 브랜치 오픈채팅 체험데모용 GPT DB

## 고정 시나리오
- 부산 대학가
- 자본 5,000만원
- 고기덮밥
- 대표 자가 브랜드: 육반장
- 프랜차이즈 비교: 동종 유사군 + 동래정 공개페이지 샘플

## 데이터 상태 구분
- `confidence_score >= 0.8`: 공식 또는 널리 확인 가능한 공개 홈페이지
- `0.5~0.79`: 공개 페이지이나 실제 거래조건 확인 필요
- `< 0.5`: 화면 동작을 위한 데모 가정

## 중요한 주의
- 프랜차이즈 비용·수익은 보장값이 아니다.
- 공급처 가격은 대부분 견적 전 후보 데이터다.
- 상담사 프로필과 슬롯은 대기 흐름 시연용 mock이다.
- 실제 계약·인허가·시공 전 전문가와 관할 기관 확인이 필요하다.

## Codex 사용 방식
1. 각 JSON을 `src/data`로 복사하거나 서버에서 import한다.
2. 모든 화면은 API 없이 로컬 JSON만으로 동작 가능해야 한다.
3. 상담신청·피드백은 초기에는 localStorage/mock API로 저장한다.
4. `confidence_score`, `data_note`, `warning_notes`를 UI에 표시한다.
