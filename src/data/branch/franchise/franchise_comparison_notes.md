# 프랜차이즈 비교 데이터 사용 원칙

## 목적
프랜차이즈를 부정적으로 묘사하는 것이 아니라, 동일 자본에서 프랜차이즈와 자가 브랜드 창업안의 비용·지원·자유도 차이를 비교한다.

## 반드시 구분할 것
- 본사 또는 플랫폼이 입력한 홍보성 수치
- 공정거래위원회 정보공개서에서 확인한 수치
- 브랜치의 데모 가정
- 실제 견적을 통해 확인된 수치

## 화면 표시 원칙
1. 본사 입력 수치는 `본사 입력·재확인 필요` 표시
2. 정보공개서 수치는 기준연도 표시
3. 데모 평균은 `시연용 가정` 표시
4. 예상 수익은 보장 표현 금지
5. 프랜차이즈가 더 유리할 수 있는 경우를 함께 표시

## 자가 브랜드가 유리할 가능성이 높은 경우
- 본인이 매장 운영에 직접 참여할 수 있음
- 메뉴와 공급처를 직접 관리할 의지가 있음
- 소형 매장 또는 배달혼합형으로 시작함
- 지역 고객에 맞춘 브랜드·메뉴 조정이 중요함

## 프랜차이즈가 유리할 가능성이 높은 경우
- 외식업 경험이 거의 없고 표준 매뉴얼 의존도가 높음
- 브랜드 인지도가 초기 매출에 결정적임
- 본사의 교육·물류·신제품 개발 역량이 검증됨
- 초기 자본 여력이 충분하고 자유도보다 안정적 운영을 중시함
