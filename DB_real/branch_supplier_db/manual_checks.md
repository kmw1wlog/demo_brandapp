# 남은 수동 확인사항

## 모든 SKU 공통
- 실제 상품 상세페이지 접속 및 품절 여부 재확인
- 부산 배송 가능 여부
- 냉장·냉동 배송 방식
- 배송비와 무료배송 기준
- 부가세 포함 여부
- 최소 주문 수량
- 사업자 회원 가입 필요 여부
- 세금계산서 발행 여부
- 주문 마감시간과 리드타임
- 반품·클레임 정책

## 육류
- 우삼겹의 정확한 부위명과 원산지
- 박스 총중량과 kg 단가/박스가 구분
- 슬라이스 두께
- 해동육 여부
- 중량 손실 및 드립률
- 샘플 테스트
- 동일 규격 공동구매 가능 여부

## 쌀
- 품종과 생산연도
- 단일미·혼합미
- 도정일
- 20kg 실제 배송비
- 정기납품 단가

## 채소·마늘
- 표시가격이 박스 총액인지 단위당 가격인지
- 산지와 등급
- 신선·냉동 구분
- 수율과 폐기율
- 직배송 가능 요일

## 계란
- 한 판 가격과 묶음 최소 주문량
- 크기 등급
- 세척란 여부
- 냉장 배송
- 공개 쿠폰가 적용 조건

## 포장재
- 용기와 뚜껑 포함 여부
- 전자레인지 가능 여부
- 내열온도
- 밀폐 테스트
- 실제 개당 단가
- 샘플 주문 여부
- 로고 인쇄 MOQ와 판비

## 동적 가격 수집
- 식봄 제휴 API·CSV 제공 여부
- 판매자별 가격 변경 알림 또는 발주 데이터 제공 여부
- 미트박스 사전 사용 허가 및 제휴 데이터 제공 여부
- Naver Shopping 검색 결과와 내부 SKU 매칭 규칙
- KAMIS 품목코드와 내부 ingredient_id 매핑
